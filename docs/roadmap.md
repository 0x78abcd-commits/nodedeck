## P1：价值高、工作量小到中

| # | 功能 | 来源 | 说明 | 状态 |
|---|---|---|---|---|
| 1 | 一键体检 + 被墙检测 | TMS 0.1.26 / 0.1.31 / 0.1.32 | 按顺序查：SSH 能连 → 服务在跑 → 本机连端口 → 海外连端口（check-host.net）→ 节点真连 → 出口 IP；在断点给出结论（如"海外通、国内不通 = IP 被墙"）和下一步建议；附 ping.pe 复核链接 | ✅ 0.2.0 |
| 2 | 部署后自动测端口，不通自动换 | TMS 0.1.29 | TCP 协议部署完从本机测端口，不通换随机端口重试，最多 3 次；用户手填的端口不自动换 | ✅ 0.2.0 |
| 3 | SSH 直连不通自动走本机代理 | TMS 0.1.32 | 国内直连 VPS 的 SSH 常被干扰；超时且检测到 V2rayN/Clash 本地端口时经代理重连，密码错误不重试 | ✅ 0.2.0 |
| 4 | 每月流量自动重置 + 「在用」状态 | TMS 0.1.27 / 0.1.58 | 用户可设每月重置日，agent 到点清零；用户列表显示最近 30 秒是否在用 / 最后在用时间 | ⬜ |
| 5 | 落地支持机场节点 + 批量导入 + 分组 | TMS 0.1.21 / 0.1.33 / 0.1.58 | 落地除 SOCKS5/HTTP 外支持 vless/vmess/trojan/ss/hy2 链接或订阅；一次粘贴多条；按国家分组筛选；改落地后自动同步相关服务器 | ⬜ |
| 6 | Cloudflare 隧道模式 | newsuoha.sh | VPS 不开端口、IP 被墙也能用；用 sing-box 1.14 内置的 cloudflared 入站（需自有域名 + 隧道令牌）；配合优选 CDN 地址生成多个入口 | ⬜ |
| 7 | 支持 Alpine / OpenRC、armv7 | newsuoha.sh | 很多便宜 NAT 小鸡是 Alpine；部署脚本和 agent 支持 OpenRC，CI 增加 armv7 构建 | ⬜ |
| 8 | 内核升级时间段 | 自己的需求 | 只在设定时段（如凌晨 3–5 点）自动升级 sing-box，避免白天断线 | ⬜ |

## 同类开源项目借鉴（2026-11-22 调研）

参考：3X-UI、S-UI、Marzban / Marzneshin、Remnawave、Hiddify、sing-box-yg / argosbx、fscarmen/sing-box、raven-subscribe。只借鉴思路。

| # | 功能 | 来源 | 说明 | 状态 |
|---|---|---|---|---|
| R1 | sing-box 订阅格式 | Marzban、Hiddify | 除 v2rayN / Clash 外再出 sing-box JSON（SFA / SFI / Hiddify / NekoBox），按客户端自动识别 | ⬜ |

| R4 | 订阅信息页 | x-ui、Hiddify | 浏览器打开订阅地址时显示用量、到期、二维码、各客户端一键导入；响应头带 profile-web-page-url | ⬜ |
| R5 | Telegram 通知 | 3X-UI | 每日流量报告、用户快到期 / 快用完提醒、用户被停用、内核升级结果；由 VPS 上的 agent 发送，电脑关机也能收到 | ⬜ |

| R9 | 节点被墙一键换新 | raven-subscribe | 一键换端口 + Reality 密钥 + ID 并同步，用户刷新订阅即可 | ✅ 0.2.0 |
| R10 | 订阅接口限流 | S-UI-X | 订阅地址按 IP 限频，防扫描 | ✅ 0.2.0 |
| R11 | Reality 目标自动扫描 | Hiddify-Reality-Scanner | 在 VPS 附近 IP 段里找支持 TLS1.3 + H2 的网站，自动推荐最佳 SNI | ⬜ |
